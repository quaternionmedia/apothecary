# Reviewed: the systems, the tests and the docs

*Dated 2026-10-24. A review of apothecary at `build/window-views` d9c9a90
(#66, the top of the stack): its systems and code, its tests and its
documentation, each read once for gaps by a read-only pass of its own, and
what stands on origin. Each gap names its evidence and a next step; none is
fixed here. Line counts are `wc -l`, times are `tests/e2e/durations.json`
at d9c9a90, pull requests are `gh pr list` on the day. Plans are dated and
exempt from the durable-text rule.*

## The most important, in order

1. **E-STOP waits behind the exchange in flight.** An M112 sent during a
   homing or a bed probe is not written until that exchange ends
   ([Safety](#safety)).
2. **CI renders with Ubuntu's OpenSCAD 2021.01**, so every test that needs
   a newer one skips there, every run ([Tests](#tests)).
3. **Nothing has reached `main` since 2026-08-11**: the stack is open end
   to end, every branch below #66 fails the dependency audit, and GitHub
   holds 77 dependency alerts against `main`, 7 of them critical
   ([Delivery](#delivery)).
4. **The focused-systems round left two guides behind**: `docs/firmware.md`
   and `docs/bench-checklist.md` describe the Machine as one panel
   ([Docs](#docs)).
5. **No guide says how to add a focused system or a window**: the
   registry's fields and the window manager's API are explained only in
   code headers ([Docs](#docs)).
6. **The browser suite walks its loops two and three times**, and copies
   its ring helpers into a third of its files ([Tests](#tests)).

## Safety

- **[high] E-STOP (M112) waits for the link's lock with no limit, then for
  an `ok` a halted board never sends.** `apothecary/firmware/gcode.py:686`
  (`self._lock.acquire(timeout=-1 ...)`); `control_printer` at
  `gcode.py:1211` passes no `wait`, and `busy` extends the deadline
  (`gcode.py:713`); the path is `firmware/devices.py:735-739`; the halt line
  `Error:Printer halted` matches `ERROR_RE` and is raised. Next: write M112
  straight to the transport, outside the lock, and take the halt line as
  its answer; a test that sends M112 during a long exchange.
- **Withdrawn: "the local-only guard checks not `Origin`".** It does:
  `from_this_machine` refuses a request whose `Origin` is not this machine's
  and a cross-site `Sec-Fetch-Site` that is not a navigation
  (`apothecary/stays_local.py:591-598`), and `tests/test_stays_local.py:782-789`
  holds it; the pass that read it searched for the header names in their
  capitalised form.
- **[medium] Installer downloads are checked by size and SHA-256 only**: no
  GPG signature, no macOS code signature or Windows Authenticode, and
  codeload source tarballs not at all. `todo.md:20-26`. Next: verify the
  `.asc` of OpenSCAD and arduino-cli first.
- **[medium] The control latch is timed by the wall clock**, so a clock step
  (NTP, a suspend) lengthens or ends an armed window. `gcode.py:1104-1130`
  (`time.time()`). Next: `time.monotonic()`.
- **[low] Jogs are limited per move only**: in relative mode repeated jogs
  add up, and the firmware's soft endstops are the only bound.
  `gcode.py:880-919`. Next: say so in `docs/firmware.md`, or track the
  position.
- **[low] A print's `file_id` may start with a dot**, safe only because a
  suffix is appended. `firmware/models.py:525`, `firmware/devices.py:938-943`.
  Next: refuse a leading dot.
- **[low] `rust_installer.unpack`'s fallback for Python 3.11.0-3.11.3 extracts
  without `filter="data"` and checks member names, not link targets.**
  `firmware/rust_installer.py:362-366`. Next: refuse link members, or
  require 3.11.4.
- **[low] Part names go into three fetch URLs unencoded.**
  `templates/fractal_viewer.html.j2:5403,6028,6029`. Next: `encodeURIComponent`
  as everywhere else.
- **[low] `demo.py`'s subprocess calls have no timeout**, under
  `serve --demo`. `apothecary/demo.py:112,118,128`.

## Tests

### What runs where

- **[high] CI installs Ubuntu's OpenSCAD (2021.01)**
  (`.github/workflows/pytest.yml`, "Install OpenSCAD", both jobs), so every
  test that needs a snapshot skips there: `tests/test_customizer_params.py`
  (two), `test_param_controls.py`, `test_saved_variants.py`, the listing path
  of `test_part_drafts.py`, `test_stl_renderer.py` ("writes no summary"), and
  very likely `test_kernel_comparison.py` (Manifold). Next:
  `apothecary openscad install` in CI, or `-rs` and a failure when the skips
  grow.
- **[high] The doc-capture tests run nowhere on their own**:
  `test_docs_fractal_viewer.py` and `test_docs_printer_monitor.py` skip
  without `--generate-docs`, and no workflow passes it. Next: a scheduled
  `apothecary docs generate`.
- **[medium] CI tests Python 3.11 only** (`pytest.yml`, `integrates.yml`,
  `leak-check.yml`); development is on 3.12. Next: one unit job on the
  newest Python.
- **[medium] No test has a time limit of its own**: a hung wait takes a
  shard's 20 minutes, whose runs are some 520 s. Next: pytest-timeout with
  a generous cap.
- **[low] The window manager's harness starts no server but skips without
  `--start-server` or `--base-url`**, and is marked `e2e`, so `uv run pytest`

- **[low] `--slow` marks no browser test**, though `tests/e2e/README.md`
